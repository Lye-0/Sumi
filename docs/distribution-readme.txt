Sumi — Windows screenshot assistant

ZIPをフォルダーごと展開し、Sumi.exeを起動してください。
本体はSumi.exeにまとめています。docsには説明とライセンスを収録しています。
.NETランタイムはEXEに同梱済みです。起動時に一部のファイルをユーザー用の一時領域へ展開します。別途Ollamaと画像入力対応のローカルモデルが必要です。
Windows x64ではwin-x64、Windows on Armではwin-arm64を選択してください。

終了後はフォルダー全体を移動できます。インストール・自動起動登録は行いません。
設定は通常 %LOCALAPPDATA%\Sumi に保存されます。本体とは独立しています。
--data-dir <directory> または SUMI_DATA_DIR で設定の保存場所を指定できます。
右上の×はトレイへ格納します。終了する場合は「終了」を選択してください。
